# Carlos Medya Interactive Site

Bu depo, Carlos Medya ajansı için hazırlanmış modern ve animasyon ağırlıklı tek sayfalık web sitesini içerir.

## Yerelde Çalıştırma
1. Gerekli bağımlılıkları kurun:
   ```bash
   npm install
   ```
2. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
   Komut çalıştıktan sonra terminalde gözüken adresi (genellikle `http://localhost:5173`) tarayıcınızda açın.
3. Üretim derlemesini görmek için:
   ```bash
   npm run build
   npm run preview
   ```
   Önizleme sunucusu varsayılan olarak `http://localhost:4173` adresinden ulaşılabilir.

## Ekran Görüntüsü
Yerel sunucudan alınmış güncel ana sayfa ekran görüntüsünü proje incelemesinde bulabilirsiniz.
